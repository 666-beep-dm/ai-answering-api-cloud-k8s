# AI Answering API — Enterprise RAG Platform

## Overview

AI Answering API is a production-oriented Retrieval-Augmented Generation (RAG) platform designed for scalable AI-powered question answering.

The system allows users to upload documents, automatically index their content into a vector database, and receive context-aware answers generated by a Large Language Model.

The project demonstrates modern backend engineering practices including Clean Architecture, asynchronous processing, cloud-native deployment, observability, containerization, and scalable AI infrastructure.

---

## Key Features

### Document Ingestion Pipeline

Users can upload:

* PDF documents
* Text files

Uploaded files are:

1. Stored in S3-compatible storage
2. Registered in PostgreSQL
3. Parsed and processed asynchronously
4. Split into semantic chunks
5. Embedded using Sentence Transformers
6. Indexed into Qdrant Vector Database

---

### Retrieval-Augmented Generation (RAG)

The platform implements a complete RAG workflow:

```text
User Question
      │
      ▼
Embedding Generation
      │
      ▼
Qdrant Vector Search
      │
      ▼
Relevant Context Retrieval
      │
      ▼
OpenAI LLM
      │
      ▼
Streaming AI Response
```

This approach improves answer quality while reducing hallucinations by grounding responses in uploaded knowledge.

## API Endpoints

### Upload Documents

```http
POST /api/v1/upload
```

Uploads a file and starts asynchronous indexing.

### Ask Questions

```http
POST /api/v1/ask
```

Returns streamed AI-generated responses based on indexed knowledge.

### Health Check

```http
GET /api/v1/health
```

Service health monitoring.

### Metrics

```http
GET /metrics
```

Prometheus-compatible metrics endpoint.
